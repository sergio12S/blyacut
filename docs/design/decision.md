# BlyaCut: итог дизайн-роя GBRAIN — 18.10.2026

Рой запущен через GBRAIN в общей рабочей папке, с отдельной областью документов для каждого участника. Claude и AGY завершили предметные брифы и автономные HTML-прототипы. Grok через OMP/OpenRouter не выполнил работу: API повторно вернул HTTP 402 при резервировании 65536 выходных токенов; один старый fast-вариант также вернул 404. Смена модели и локальная попытка ограничить запрос не помогли. Кредиты не покупались, глобальные настройки не менялись. Визуальную систему ниже свёл Codex из проверенных предложений и текущего интерфейса; авторства Grok у неё нет.

HTML открывается локально без сети. Это макеты с демонстрационными данными, не подключённый к Rust редактор. Проверка структуры артефактов пройдена; это не доказательство пользовательского удобства или работоспособности изображённых функций. Браузерный визуальный просмотр со стороны основного агента не завершён: браузерный адаптер недоступен, нативный Chrome занят пользователем. Заявления участников о собственном просмотре — отдельно от нашей проверки.

## Принятые решения

1. Монитор и таймлайн — главные рабочие поверхности. Нейтральные тёмные панели, один лаймовый акцент действия/выделения. Видео — бирюзовое, звук — фиолетовый, агент — синий. Тип и состояние всегда сопровождаются текстом.
2. Правый док разделён на «Inspector / Agent». Настройки клипа не конкурируют с подключением и предложениями агента. Тело каждой вкладки прокручивается независимо; вкладка агента показывает число ожидающих правок.
3. Перед применением агентского предложения человек читает список действий с именами медиа и временем. JSON доступен в раскрываемых технических деталях. Проверка ревизии, подтверждение удаления/большого батча и единый Undo остаются в Rust.
4. Компактная шапка 52 px, строки дорожек 56 px, масштабируемая высота таймлайна 210–340 px. Базовый текст 13 px, вспомогательные подписи постепенно приводятся к 11 px. Фокус клавиатуры видим. Вкладки работают стрелками/Home/End.
5. Агент творит через явные возможности: импорт существующих/внешне сгенерированных файлов, композиция дорожек, обработка рецептами, проверка результата и экспорт. В редакторе нет ложного поля чата, обещающего встроенную генерацию.
6. Рецепты эффектов загружаются во время работы и сохраняются копией в проект. Для новых комбинаций существующих примитивов переустановка не нужна. Новые алгоритмы через шейдеры/DSP — следующий отдельный этап, с одинаковым контрактом превью и экспорта.

Первую интеграцию проверили в отдельной нативной QA-сборке: переключение вкладок мышью и стрелкой, читаемое предложение и его применение, компактный инспектор, сохранение/открытие эффектов и монохромный кадр в превью. Размер окна — стандартный; минимальный размер пока не проверен.

Первая интеграция уже в `src/App.vue`, `src/components/AgentPanel.vue`, `src/edit-description.ts`, `src/design-tokens.css` и `src/style.css`. Данные проекта и команды остаются прежними.

## Что не принято как готовое

В первоначальном брифе AGY были неточности: inverse patches/выборочный Undo, структурированные HTTP409 ошибки, leases дорожек, подписи происхождения, capabilities_list, YAML и произвольные FFmpeg-графы. Участнику отправлена проверка по исходникам; это предложения, а не действующий API. В исходном брифе Claude статус эффектов устарел из-за параллельной реализации; он обновлён. Таблица будущих горячих клавиш в брифе описывает план, а не весь набор уже реализованных сочетаний.

## Следующие изменения

- Визуальный diff из существующего `Proposal.preview`: удаляемые интервалы, новые клипы, изменённые параметры; до/после в мониторе.
- Таймкод вместо миллисекунд, мышиный трим/перемещение звука с предварительным отображением результата и одной командой на отпускание.
- Изменяемые сплиттеры панелей и режим узкого окна; сохранение расположения.
- `capabilities` и структурированные ошибки/recovery для агентов, идентификаторы задач и журнал происхождения. Сейчас MCP отдаёт схемы инструментов, ревизию и последний render job.
- Проектирование shader/DSP ABI после проверки паритета превью/экспорта. Нельзя выдавать текущие JSON-рецепты за поддержку произвольных программируемых эффектов.

Открытая пользовательская сессия не перезапускалась и не редактировалась ради обновления дизайна. Новые сборки готовятся на диске; отдельная QA-сборка использует иной application ID.
