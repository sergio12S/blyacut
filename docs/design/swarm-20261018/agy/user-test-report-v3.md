## 6. Эргономика API наложений: что удобно, а что неудобно

### Удобно:
1. **Немагнитные оверлейные дорожки**: Клипы на дорожках `V2+` не смещают соседей при вставке или удалении, что позволяет точно выставлять PiP и титры по таймкодам через `move_clip`.
2. **Нормализованные координаты `x_milli` / `y_milli` / `scale_milli` / `opacity_milli`**: Независимость от разрешения проекта (1080p, 4K) — координаты задаются в долях от 0 до 1000.
3. **Инструмент `create_text_overlay`**: Генерирует прозрачный PNG с мягкой тенью под текстом, обеспечивая читаемость на любых фонах без создания отдельных подложек.
4. **Сквозная композиция в `preview_frame`**: Возможность видеть все слои в реальном композитинге до запуска тяжелого рендера всего видео.

### Неудобно:
1. **Запрет на перекрытие клипов на одной оверлейной дорожке (`c.position_ms < end`)**:  
   На одной дорожке оверлеев нельзя одновременно держать два элемента (например, титр и PiP). Для одновременного показа приходится создавать несколько отдельных оверлейных видеодорожек (`track-pip`, `track-text`).
2. **Дефолтная длительность статических картинок**:  
   При импорте PNG через `create_text_overlay` длительность ассета по умолчанию составляет 1 час (3 600 000 мс). Если агент забывает сделать `trim_clip(end_ms = 4000)`, длительность проекта подскакивает до часа. Было бы удобнее добавить аргумент `duration_ms` прямо в `create_text_overlay` (как в `create_title_card`).
3. **Центральная привязка координат**:  
   Координаты `x_milli` и `y_milli` определяют центр накладываемого клипа. Для размещения PiP в углу агенту приходится вычислять отступ с учётом половины масштаба `scale_milli`. Добавление пресетов привязки (`anchor: "top_right"`, `"bottom_right"`) существенно упростило бы автономное позиционирование.

## 8. Итоговая оценка и Топ-3 улучшения

### Итоговая оценка: 9.9 / 10
BlyaCut v3 с поддержкой многослойного композитинга, прозрачных наложений, PiP и независимых оверлейных дорожек предоставляет полноценную среду для сложного профессионального видеомонтажа автономными агентами.

### Топ-3 предложения по развитию:
1. **Параметр `duration_ms` в `create_text_overlay`**: Автоматически обрезать титр до заданной длительности при импорте, избавляя агента от обязательного второго вызова `trim_clip`.
2. **Пресеты углов для `set_transform` (`anchor`)**: Поддержка флагов `corner: "top_right" | "top_left" | "bottom_right" | "bottom_left"` с автоматическим расчётом безопасных отступов от границ кадра.
3. **Анимация движения наложений (Keyframes / Transition)**: Возможность плавной анимации появления PiP (выезд из-за края кадра или масштабирование от 0 до 300) через интерполяцию параметров `transform`.
