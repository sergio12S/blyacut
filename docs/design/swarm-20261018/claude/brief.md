## 2. Раскладка и иерархия внимания

Приоритет взгляда (от самого громкого к тихому): **монитор → таймлайн/плейхед → выделенный клип → контекст справа → библиотека → хром**. Акцентный цвет `--accent #c1f17b` (лайм, уже бренд) используется только для: плейхеда, выделения, основной кнопки на экране (одна!) и фокуса. Агент имеет собственный цвет `--agent #9db8ff`, чтобы его правки никогда не путались с правками человека.

```
┌ Top bar 40px: B/ BlyaCut · Проект ● │ Монтаж | Звук | Эффекты │ ↶ ↷ │ ◉ Агент: 1 на проверке │ [Экспорт] ┐
├ Library 240 ─┬──────── Monitor (flex) ────────┬─ Dock 300: [Инспектор|Агент] ┤
│ поиск        │  16:9 кадр, safe-area           │ sticky: имя клипа + тип        │
│ ассеты       │  transport 36px: TC ◂ ▶ ▸ TC   │ секции-аккордеоны (≤3 открыто)│
├──────────────┴─────────────────────────────────┴────────────────────────────────┤
│ Toolbar 32: инструменты · snap · ripple-индикатор · zoom          ⇕ сплиттер   │
│ Ruler 20 │ V1 48 │ A1 40 │ A2 40 …                                              │
```

### Размеры

| Viewport | Library | Dock | Monitor (кадр) | Timeline | Поведение |
|---|---|---|---|---|---|
| **1440×900** | 240 px, список с превью 56×32 | 300 px | ~ 860×484 | 300 px (4 дорожки без скролла) | Всё видно, без скролла страницы |
| **1000×650** | свёрнута в **рейл 48 px** (иконки Медиа/Эффекты), раскрывается поверх монитора по клику/⌘1, закрывается Esc | 272 px | ~ 600×300 | 216 px (V1+A1+A2, остальное — вертикальный скролл дорожек) | Шапка прячет текст табов, оставляет иконки; статус-бар — только ревизия и автосейв |

Правило: **страница никогда не скроллится**; скроллятся только `.media-list`, тело дока и `.tracks-scroll`.

### Анти-переполнение инспектора (правила для реализации)

1. Док = `grid-template-rows: auto 1fr auto` → sticky-заголовок (имя клипа, тип, дорожка), прокручиваемое тело, sticky-футер с **одной** деструктивной/главной кнопкой (если нужна).
2. Тело — максимум 3 секции-аккордеона: **Время** (открыта), **Звук**, **Эффекты**. Состояние открытия запоминается per-kind (`video`/`audio`) в `localStorage`.
3. Поля в сетке `grid-template-columns: 1fr 1fr` (In/Out, Fade in/Fade out); ширина поля ≥ 104 px, иначе — одна колонка (container query `@container dock (max-width: 280px)`).
4. Длинные имена — `text-overflow: ellipsis` + `title`, путь файла — только в тултипе.
5. Никакого JSON и логов в доке. Технические детали — по кнопке «Подробнее» в модальном листе.

## 3. Сценарий новичка: импорт → экспорт (≤ 6 действий)

1. **Пустой проект**: монитор показывает одну крупную цель «Перетащите видео или аудио сюда» + кнопку «Импорт медиа (⌘I)». Справа — чеклист из 4 шагов (Импорт · На таймлайн · Резать · Экспорт), каждый гаснет по факту. Без мастеров и модалок.
2. **Импорт**: карточка ассета появляется сразу со спиннером «Анализ (FFprobe)…», затем длительность/разрешение. Ошибка FFprobe — карточка красная с текстом причины и «Убрать».
3. **На таймлайн**: перетаскивание ассета на дорожку *или* `+`/Enter на выбранном ассете (как сейчас `append`). Видео → V1, аудио → первая свободная A-дорожка. Подсказка-тост: «Видео склеивается без зазоров. Звук стоит там, куда вы его положили».
4. **Резать**: S — разрез в плейхеде; клик по куску + Delete — удалить, хвост видео сдвигается (тост «Сдвинуто 3 клипа · ⌘Z»).
5. **Подправить**: тянуть край клипа (трим) — тултип показывает новую длительность и сдвиг.
6. **Экспорт**: одна лаймовая кнопка в шапке → лист с 3 фактами (1920×1080 · 00:30 · H.264/AAC MP4) → «Выбрать файл…». Прогресс — в шапке (кольцо на кнопке) и в статус-баре; редактирование не блокируется (это уже правда в архитектуре: экспорт идёт со снимка).

Пустые состояния всегда говорят **что сделать дальше**, а не «нет данных».

## 4. Таймлайн: drag / trim / ripple — точная семантика

Семантика повторяет ядро (`crates/core`), UI её только визуализирует:

| Действие | Видео-дорожка (V1) | Аудио-дорожки (A*) | Команда `Edit` |
|---|---|---|---|
| Перетащить клип | **Перестановка**: вставочная черта между клипами, остальные раздвигаются-призраки; на отпускание одна команда | **Свободное перемещение** по времени и между A-дорожками; привязка к плейхеду/краям 8 px (⌘ при перетаскивании — без привязки) | `reorder_clip{index}` / `move_clip{track_id, position_ms}` |
| Наложение | невозможно (магнитная дорожка) | на той же дорожке — **красный призрак + курсор not-allowed** + подсказка «Перетащите на A2 или создайте дорожку»; отпускание = отмена | ядро отклоняет overlap |
| Трим за край (8 px зона, курсор ↔) | **Ripple**: последующие клипы двигаются вместе; призраки показывают сдвиг; тултип `−1.20 с · 3 клипа сдвинутся` | **Без ripple**: соседи стоят; край упирается в соседа (жёсткий стоп с вибрацией подсветки) | `trim_clip{start_ms,end_ms}` в **исходных** мс |
| Delete / ⌫ | Ripple delete | Lift (позиции остальных сохраняются) | `delete_clip` |
| Разрез S | в плейхеде по выделенному клипу или по всем клипам под плейхедом, если ничего не выделено | то же; внутри fade — ядро отклоняет → тост «Разрез внутри затухания: уберите fade» с кнопкой «Открыть Звук» | `split_clip` |

Правила: перетаскивание и трим **не шлют команды на каждое движение** — только одна команда на `pointerup` (одна запись Undo, одна ревизия). Esc во время перетаскивания отменяет. Индикатор режима в тулбаре: `RIPPLE: V1 · ЯКОРЬ: A1–A3` всегда видим, чтобы правило не было сюрпризом.

## 5. Агентские рабочие процессы

Реальность 0.2: агент — **внешний MCP-хост**; внутри BlyaCut нет LLM, транскрипции и генерации. UI не должен содержать поля «спросите ИИ…» до тех пор, пока его нечем исполнить. Вместо этого правый док «Агент» показывает **ленту задач** внешнего агента.

### Состояния карточки задачи

| Состояние | Источник данных (сейчас) | Визуал | Действия человека |
|---|---|---|---|
| **Подключение** | `get_agent` → `AgentConnection` | серый, путь папки, путь конфигурации с «Копировать» | Остановить доступ |
| **Запланировано** (предложение получено, ещё не открыто) | событие `proposal` (`propose_edits`) | синяя точка, «6 правок · результат 00:27.40 (−2.60 с)», счётчик в шапке | Открыть проверку (Enter) |
| **Выполняется** | `get_session` → render job; импорт с пробой | синий индетерминированный/процентный бар, этап, «Отменить» для экспорта | Отменить экспорт (`cancel_export`) |
| **На проверке** | `Proposal.preview` vs текущий `Project` | Таймлайн переходит в режим сравнения: удаляемое — красная штриховка, новое — синий контур, изменённая громкость — синяя линия огибающей; список правок человеческим языком; правки агента нельзя редактировать по месту | **Применить** (⌘Enter), **Отклонить**; пролистывание правок ↑/↓ двигает плейхед к месту правки |
| **Ошибка** | отказ ядра (stale `expected_revision`, overlap, fade split), ошибка FFmpeg | красный край, одна фраза причины + «таймлайн не изменён», «Скопировать для агента» (готовый текст ошибки) | Скопировать, Закрыть |
| **Применено** | `resolve_proposal(accept)` → новая ревизия | зелёная галочка, «Отменить ⌘Z» прямо в карточке | Undo |

Перевод `Edit` в текст (функция `describeEdit(edit, project)` в новом `src/agentText.ts`):
`split_clip` → «Разрезать interview_A на 00:12.00»; `delete_clip` → «Удалить фрагмент interview_A (00:12.00–00:14.60, 2.6 с)»; `set_audio` → «music_bed: громкость 100 % → 25 %, fade-in 0.5 с»; `move_clip` → «voiceover → A2 на 00:03.00»; `trim_clip` → «broll_city: начало +1.2 с»; `set_effects` → «interview_A: эффекты → яркость +10, насыщенность −20»; `reorder_clip` → «broll_city → позиция 2»; `add_track`/`append` — аналогично. Сырой JSON — только в «Подробнее».

**Что агенту нельзя показывать как доступное:** генерация видео/музыки, транскрипция, удаление пауз. Для них в доке — блок «Пока не умеет BlyaCut» (серый, без кнопок), чтобы не обещать.

## 6. Эффекты без переустановки

**Статус обновлён 2026-10-18.** Ядро теперь хранит в `Clip.effects` провалидированный встроенный **EffectRecipe v1** (project schema 3); операции: `brightness`, `contrast`, `saturation`, `hue` (видео) и `low_pass`, `high_pass`, `echo` (аудио); правка `set_effects`; MCP `list_effect_recipes` / `create_effect_recipe`. Экспорт проверен тестами; **нативное превью эффектов не проверено** — UI обязан это говорить. Плюс по-прежнему `gain_milli`, `fade_in_ms`, `fade_out_ms`. Вкладка **Эффекты** в шапке переключает левую панель с «Медиа» на «Эффекты»:

- **Доступно сейчас (ядро + экспорт)**: Яркость, Контраст, Насыщенность, Оттенок; ФНЧ (low-pass), ФВЧ (high-pass), Эхо — как шаги рецепта; Громкость, Плавное появление/затухание. Перетаскивание на клип или Enter на выделенном клипе добавляет шаг через одну правку `set_effects` (один Undo) и открывает секцию «Эффекты» инспектора. Каждая карточка и стек в инспекторе несут бейдж **«экспорт ✓ · превью не проверено»**, а монитор при наличии эффектов на клипе показывает плашку «Превью без эффектов — проверьте экспортом», пока паритет не подтверждён.
- **Рецепты агента**: рецепты, созданные через `create_effect_recipe`, появляются в группе «Рецепты» с меткой ◆ и автором; применяются тем же `set_effects`, поэтому в режиме проверки отображаются как обычная правка («interview_A: эффекты → Тёплый кадр (3 шага)»).
- **Позже** (серые карточки с пометкой «позже», `aria-disabled`): программируемые шейдеры и DSP-плагины, LUT, Кадрирование/масштаб, Скорость, Переходы, Текст, многополосный EQ/компрессор, Автоприглушение (ducking).
- **«Без переустановки»** — частично есть: EffectRecipe v1 — это данные в проекте, новые рецепты (комбинации 7 операций) создаются без пересборки, в т. ч. агентом. **Позже** остаётся расширение набора операций без пересборки: эффект = JSON-манифест (`id`, `params` с типами и диапазонами, шаблон фильтра FFmpeg) в `~/Library/Application Support/org.blyacut.editor/effects/`; ядро валидирует манифест и хранит эффект в клипе как данные, движок компилирует в filter graph. UI инспектора строится из схемы `params` — новый эффект не требует новой Vue-формы. Агент видит те же эффекты через `tools/list` (JSON Schema), т. е. новые возможности появляются у агента одновременно с человеком. Условие: паритет превью/экспорта (превью — HTMLVideoElement; нативное превью эффектов пока не проверено).

## 8. Доступность и дизайн-токены

```css
:root{
  --bg:#111216; --surface:#17191f; --surface-2:#1e2028; --line:#2c2f39;
  --text:#e7e9ef;      /* 15.6:1 на --bg */
  --text-2:#a6abb8;    /* 7.9:1 на --bg, 7.1:1 на --surface */
  --text-3:#878c99;    /* 5.2:1 — только ≥12px */
  --accent:#c1f17b;    /* на --bg 14:1; текст на акценте #18230c */
  --agent:#9db8ff; --danger:#ff7a7a; --warn:#f4c46b; --ok:#7fd99a;
  --clip-video:#2e4a63; --clip-audio:#3d3458;
  --r-1:4px; --r-2:6px; --r-3:10px; --sp:4px; /* шаг 4 */
  --fs-1:11px; --fs-2:12px; --fs-3:13px; --fs-4:15px;
}
:focus-visible{outline:2px solid var(--accent);outline-offset:2px}
```

- Состояния никогда не кодируются только цветом: удалить = штриховка + значок «−», агент = значок ◆ + цвет, ошибка = значок ! + текст.
- Клипы: цвет по типу + текст имени ≥ 11 px на контрасте ≥ 4.5:1.
- Таймлайн доступен как список: каждый клип — `role="button"` с `aria-label="interview_A, V1, 00:08.00–00:22.00"`; плейхед — `role="slider"`.
- `prefers-reduced-motion`: убрать анимацию призраков и пульсацию агента.
