## Новое
- Первая видеодорожка — главная (магнитная). Дорожки, добавленные через `add_track` с `kind: "video"`, — **наложения** (V2, V3…): клипы стоят там, где их поставили, без сдвига соседей.
- Правка `set_transform`: `{clip_id, transform: {x_milli, y_milli, scale_milli, opacity_milli}}` (центр клипа в долях кадра ×1000, масштаб относительно «вписать в кадр», 10..4000; `null` — во весь кадр).
- `create_text_overlay {text, output_path(.png), position: top|center|bottom, text_color}` — прозрачный PNG с текстом и тенью, сразу импортируется как картинка. На дорожке наложений: `append` → `move_clip` (время старта) → `trim_clip` (`end_ms` = длительность).
- `import_media` принимает PNG/JPEG/WebP.
- `preview_frame` показывает и наложения — проверяй ими композицию.
- Подробно: `docs/mcp.md`.
