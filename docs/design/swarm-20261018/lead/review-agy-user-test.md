## Реальные улучшения (приоритет лида)
1. **Ошибка устаревшей ревизии с числами** (`expected N, current M`) — дёшево, сильно помогает агентам.
2. **`preview_frame` в MCP** — агент «слепой» до полного экспорта; один кадр через движок решает это.
3. **Предупреждение о хвостах**: `get_timeline` или ответ `apply_edits` должен сообщать «видео короче аудио на X с — будет чёрный кадр».
4. **Измерение громкости** после экспорта в `get_session` (peak/mean) — агенты не ставят мастеринг сами.
5. **Титры/текст** — нужен ffmpeg с freetype или свой рендер текста; без этого промо без слов.

`reorder_clip.index` задокументирован в схеме инструмента; алиас `new_index` не нужен. `complete` vs `completed` — не проблема.
